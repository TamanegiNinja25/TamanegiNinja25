## 🎮 Featured project: Cursed Chronicles

<a href="https://github.com/TamanegiNinja25/JJK-Mobile-Game"><img src="https://raw.githubusercontent.com/TamanegiNinja25/JJK-Mobile-Game/main/docs/screenshots/title.jpg" width="640" alt="Cursed Chronicles title screen"></a>

A Zenonia-style action RPG for Android set in the world of Jujutsu Kaisen. Play as Yuji,
Megumi or Nobara through five story chapters, from Sugisawa High to the Shibuya Incident,
with skill trees, loot, boss fights and Domain Expansions. Every model, sound and icon is
generated in code with TypeScript and three.js, and the game runs fully offline.
